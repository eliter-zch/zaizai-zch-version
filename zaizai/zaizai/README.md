# 仔仔 · ZAIZAI ARENA

根据《仔仔游戏文档.docx》实现的多人网页回合游戏。支持 2–8 人，使用临时昵称，无需账号。服务端统一验证和结算，HTTP 提交操作，SSE 实时同步状态。

## 启动

需要 Node.js 22 或更新版本。游戏运行没有第三方依赖，不安装依赖也能启动。

```powershell
cd D:\Bigarm\zaizai
node server/index.js
```

浏览器访问 `http://localhost:3000`。也可以双击 `开始游戏.cmd`。如果端口占用：

```powershell
$env:PORT = '3100'
node server/index.js
```

此时访问 `http://localhost:3100`。不要直接双击 public/index.html，页面需要 Node.js 服务。

## 联机流程

1. 所有玩家访问同一台服务端的地址，各自输入昵称。
2. 创建房间，设置人数上限 2–8 人，分享房间号或邀请链接。
3. 从大厅加入，或输入房间号，或打开邀请链接。
4. 至少 2 人、所有在房玩家准备后自动开局，不要求达到人数上限。
5. 选择招式，必要时点击环形战场中的头像指定目标，再锁定。仅两人存活时，锤、枪、火球、黑天使和锤带盾默认指定对手，无需点击头像；流星锤封锁仍可手动选自己、对手或跳过。
6. 全部存活玩家锁定后同时亮招，无伤展示 2 秒，有伤展示 5 秒，自动下一回合。
7. 阵亡头像变灰且不能再出招。最后一名幸存者获胜，同时全灭则平局。
8. 全员重新准备后开始新局，生命与资源重置；房间历史战报和累计胜场保留。

每个玩家的视角均把自己放在圆环最下方，序号从小到大逆时针排列。玩家留在房间时序号保持不变；离开后空出的序号可分配给新玩家。旋转仅影响展示，不改变火球的相邻目标规则。

战场中心只显示本回合资源足够的招式，只保留招式选项与锁定按钮，金盾选中时提供反弹选择；回合时间、结算和胜负状态位于战场右上角。排行榜按钮位于环形战场内部左上角，战况记录按钮位于内部右下角，点击弹窗查看累计胜场、本局结果和历史战报；角色状态仅显示在头像下方。每局胜负一经判定即保存获胜者姓名、身份和结果，胜者在展示阶段或结束后离房都不会改变结果，胜场只累计一次。离房玩家的成绩仍保留，同一临时身份重新进房继续累计。

同一电脑可开多个普通标签页模拟多个玩家。身份保存在 sessionStorage，各标签页独立，刷新同一标签页保持身份。浏览器的“复制标签页”可能继承身份，需要用“更换临时昵称”创建新身份。

### 局域网

服务监听 0.0.0.0。用 ipconfig 查看服务端电脑 IPv4，例如 192.168.1.20，同一 Wi-Fi 的其他设备访问 `http://192.168.1.20:3000`，不能使用它们自己的 localhost。首次运行时，如 Windows 提示，允许 Node.js 在所需网络上通信。

### 互联网部署

将项目部署到支持持续运行 Node.js 的服务器或容器，启动命令 `node server/index.js`，可配置 PORT 环境变量。需要常驻服务，纯静态托管不适用。项目不会自动生成公网地址。

```sh
docker build -t zaizai-arena .
docker run --rm -p 3000:3000 zaizai-arena
```

反向代理需保留 /api/events 的 SSE 长连接，禁用缓冲、缓存，读超时至少 60 秒，正确转发 Host。Nginx 示例：

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Host $http_host;
    proxy_set_header Connection '';
    proxy_buffering off;
    proxy_cache off;
    proxy_read_timeout 120s;
}
```

房间、对局、临时身份保存在服务进程内存中，重启后清空。目前使用单进程；多个实例会形成独立大厅，需要引入共享状态后才能横向扩容。

头像下方公开显示生命、仔、圣盾、锤、防的当前数量；雪崩生效时显示各自禁用的招式。亮招时，超过两名玩家提交招式则显示定向招式的目标昵称（如“火球 → 玩家昵称”）；金盾始终显示预判反弹的招式（如“金盾：火球”）。

## 全部招式

| 招式 | 消耗 | 效果 |
| --- | --- | --- |
| 仔 | 无 | 获得 1 仔 |
| 防 | 无 | 抵挡枪、火球，并获得 1 个防 |
| 雪崩 | 3 防 | 下回合起自己禁防，其他人禁用本回合各自所选招式，直到新雪崩覆盖 |
| 锤 | 无 | 获得 1 锤；对防或锤带盾有仔扣仔、无仔扣血；免疫地震海浪 |
| 锤带盾 | 1 圣盾 | 抵挡枪、火球、地震、海浪；指定玩家进行锤击，自己也可被锤击；不增加锤或防次数 |
| 枪 | 1 仔 | 单目标 1 伤害，点数 1 |
| 火球 | 2 仔 | 目标与左右存活邻居各 1 伤害，不自伤；提交招式时两人存活则点数 2，否则 1，本回合固定 |
| 天使 | 3 仔 | 自己恢复 1 生命，无上限；本回合受到的总伤害至多 1 点 |
| 地震 | 4 仔 | 对其他所有人造成 2 伤害，点数 3 |
| 黑天使 | 5 仔 | 单目标 1 伤害，自己恢复 1 生命，点数 4；本回合受到的总伤害至多 1 点 |
| 圣盾 | 1 仔 | 抵挡除黑天使、流星锤破盾外的攻击，获得 1 圣盾 |
| 金盾 | 1 仔 | 预选枪、火球、地震、黑天使或海浪，反弹对自己的该类攻击；不能反弹锤或流星锤 |
| 海浪 | 3 圣盾 | 对其他人各 1 伤害，点数 3，反弹火球 |
| 流星锤 | 3 锤 | 免疫地震海浪；破圣盾金盾 1 伤害；亮招后封锁任意存活者招式，资源照扣 |

## 文档未明确处的约定

网页玩法手册中也有说明：

- 选招最多 15 秒，全部提前锁定即亮招；超时自动使用仔；仔被雪崩禁用时改用防，避免卡局。
- 流星锤亮招后有独立 12 秒封锁阶段，可看到全场招式，能选自己或跳过，超时跳过。选择完成后结算，再展示 2/5 秒。
- 先支付所有消耗，被封锁的招式不退资源，也不产生其他效果。多流星锤封锁同时生效，已选定封锁不因互相封锁撤销。
- 治疗与伤害同时结算，死亡不取消同回合已经发出的攻击。天使与黑天使生效时，无论单次伤害或多次攻击，本回合总伤害最多为 1 点；被流星锤封锁后回复与伤害上限保护都失效。
- 火球邻居按固定站位中的存活玩家计算，去重并排除施法者；死亡头像仍留在原位。
- 互相命中的有点数攻击逐对比较，低点数只对该对手失效，同点数对彼此的攻击抵消、双方无人受伤；群攻对其他目标照常结算。抵消后资源仍照常消耗。
- 明确的反弹优先于点数比较，否则海浪点数高于火球会让其反弹永远无法触发。
- 只反弹打到自己的一份伤害，不重放群攻，最多反弹一次；返回攻击可被原施法者的防御挡下。
- 金盾可选枪、火球、地震、黑天使或海浪；不能选择反弹锤或流星锤。
- 流星锤仅对仍生效的圣盾、金盾造成 1 点破盾伤害；封锁对方的盾后不造成破盾伤害；封锁自己则流星锤攻击失效，仍消耗锤。
- 锤带盾是独立招式，不视为出过锤、防或圣盾；雪崩禁锤或防时仍可使用，只有禁锤带盾本身才不能使用。流星锤封锁它时消耗照扣，攻击与防御全部失效。
- 普通锤与锤带盾攻击同一使用防或锤带盾的目标时，每把分别按站位结算：每次有仔扣 1 仔，无仔扣 1 血。例：1 个仔被 3 把锤指定，扣 1 仔、2 血。
- 主动离房视为弃权。锁定后目标离场则该定向招式失效，资源不退。
- 断线保留席位 60 秒可重连；超时离房，对局中视为弃权；房主离开自动移交其他玩家。

### 雪崩规则

雪崩消耗 3 个防，每次有效使用防积累 1 个防。从下一回合起，施放者禁用防，其他玩家各自禁用雪崩施放回合选择的招式。限制持续到新的有效雪崩整体替换旧限制，不叠加，也不随施放者阵亡或离房解除；新一局清空限制和资源。同回合多个有效雪崩合并覆盖：施放者全部禁用防，其余玩家禁用各自选择的招式。

流星锤封锁雪崩时仍扣除 3 个防，但不施加新限制；被封锁的防不增加防次数。超时默认出仔；若仔被禁用，则自动出防。

## 测试

规则和服务集成测试无需第三方依赖：

```powershell
npm.cmd test
```

真实浏览器测试使用 Playwright 和 Windows Edge：

```powershell
npm.cmd ci
# 另一终端启动 3100 端口的服务后
npm.cmd run test:browser
```

可通过 BROWSER_PATH 指定 Chromium 路径，通过 TEST_BASE_URL 指定测试服务地址。截图保存在 test-results/。测试覆盖多浏览器同步、8 人上限、招式保密、目标、流星锤、死亡、2/5 秒、重连和重新开局。

环境变量：PORT（默认 3000）、SELECTION_MS（15000）、INTERRUPT_MS（12000）、DISCONNECT_MS（60000）。后三项单位为毫秒。

## 文件

- server/index.js：联机服务、身份、房间、权限、回合状态机。
- server/game.js：14 种招式校验、消耗、纯函数结算。
- public/：首页、大厅、环形战场、招式、战报、手机适配。
- test/game.test.js：规则单元测试。
- test/server.test.js：多人服务集成测试。
- test/results.test.js：结果锁定、连续对局胜场、离房重进与固定序号测试。
- test/browser.mjs：三个真实独立浏览器的全流程测试。
